# Publicação do perfil de Matheus Lins Lima

Projeto criado em **Matheuslinspg3/Matheus-Lins-Lima** como uma versão preparatória.
Para aparecer automaticamente no perfil GitHub, renomeie o repositório para
**Matheuslinspg3** em Settings → General → Repository name.

O README usa SVGs armazenados na própria conta, sem JavaScript ou serviços
de estatísticas terceirizados. O logo original do Porta foi copiado do
repositório do projeto. O avatar é uma representação vetorial autoral
de rosto (sem uniforme) e pode ser editado em assets/avatar.svg.

## Atualização do gráfico

A execução 'Atualizar contribuições públicas' roda no push, diariamente
e manualmente pela aba Actions. O parser consulta o fragmento público
https://github.com/users/Matheuslinspg3/contributions e valida pelo menos
300 datas. Se o formato da página mudar, falha sem substituir o último
gráfico válido. Contribuições privadas podem não aparecer.

Se o workflow não conseguir fazer commit, ajuste:
Settings → Actions → General → Workflow permissions → Read and write permissions.

Não há placeholders falsos de contagem de contribuições; até o primeiro
sucesso o gráfico explicita que aguarda sincronização.
